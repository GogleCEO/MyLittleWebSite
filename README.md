## Сайт на тему: использование CMS в электронной коммерции (WooCommerce, Shopify, Magento)

## Есть два варианта запуска сайта:

- Локально, через открытие файла **index.html**
- Через GitHub Pages https://gogleceo.github.io/MyLittleWebSite/

## Используемые технологии:

- HTML5 - язык разметки
- Фреймворк Spectre.css
- css для стилизации
- JavaScript для кнопки бургер-меню
